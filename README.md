# RFM-анализ клиентской базы аптечной сети

## О проекте
**Цель учебного проекта:** сегментировать клиентскую базу аптечной сети и подготовить рекомендации для SMS-рассылок в связи с ожидаемым снижением выручки после завершения сезона продаж.

## Данные
Для анализа использована таблица `bonuscheques` базы **Apteka** за период **12 июля 2021 — 9 июня 2022 года**. В исследование вошли **21 075 транзакций и 5 926 бонусных карт**. Учитывались покупки, которые можно связать с распознанной картой.

## Ход исследования и результаты
Проверила качество данных, изучила распределения показателей и провела RFM-анализ клиентов с двумя и более покупками.
В ходе анализа увидела, что **2 686 клиентов (45,33%) совершили только одну покупку**. Поэтому отдельно провела **RM-анализ**, чтобы выделить группы для стимулирования второй покупки.

По результатам анализа:
- **3 240 клиентов с повторными покупками** разделены на восемь RFM-групп. Самая многочисленная — «Угасающие»: **29,17%** этой базы.
- Клиенты с одной покупкой разделены на три RM-группы. В «Приоритетные» вошли **524 клиента — 19,51%** базы RM-анализа.
- Для каждой группы подготовлены характеристики и рекомендации по взаимодействию с клиентами.

## Дашборд Metabase
Дашборд объединяет общие показатели, распределение клиентов по RFM/RM-группам и динамику покупательской активности. В публичной версии доступны фильтры периода и групп RFM/RM.
